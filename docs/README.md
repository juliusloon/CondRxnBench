# 文档导航

本目录保存项目维护者编写的设计与接口文档；本地收集的论文、补充材料和其他来源副本仍保持忽略，避免将未经许可或体积较大的资料误提交。

| 文档 | 用途 |
| --- | --- |
| [architecture.md](architecture.md) | 数据层、构建链路、验证边界与目录职责 |
| [api.md](api.md) | 当前 CSV 文件与命令行构建/验证接口 |
| [maintenance-workflow.md](maintenance-workflow.md) | 人与 AI 共用的阶段维护、交接与更新流程 |
| [`../metadata/`](../metadata/README.md) | Core v0.1 的字段语义、条件规则和 dataset cards |
| [`../adr/`](../adr/README.md) | 持久化技术决策 |
| [`../notes/`](../notes/README.md) | 每日/阶段过程笔记 |

方案讨论应先写明问题、备选方案、证据和建议；一旦形成长期约束，再新增 ADR，而不是把结论只留在过程笔记中。
